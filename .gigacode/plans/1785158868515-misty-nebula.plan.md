# AR-TileForge: План реализации

## Архитектура

### Стек технологий
- **AR-基础**: AndroidX XR Extensions (ARCore)
- **UI**: Jetpack Compose + AndroidX XR Compose
- **Рендеринг тайлов**: Compose 2D + libGDX (опционально)
- **Генерация ассетов**: KMP-логика + Compose rendering to image
- **Экспорт**: JSON + PNG

## Фаза 2: Процедурная генерация тайлов ✅

### 2.1 Tile System
**Новые файлы**:
- ✅ `tile/TileType.kt` - перечисление типов (Plains, Hills, Water, Forest, Mountain, Wasteland)
- ✅ `tile/TileData.kt` - данные тайла (type, x, y, rotation)
- ✅ `tile/TileGenerator.kt` - правила стыковки

### 2.2 Генератор карты
**Новый файл**: `tile/TileGenerator.kt`

- ✅ Start tile (равнина) в центре
- ⏳ Рекурсивное размещение с проверкой правил стыковки:
  - Вода рядом с водой → озеро
  - Холмы у воды → берег
  - Лес на равнине → лесная равнина
- ⏳ Простой noise-генератор для разнообразия

### 2.3 Tile Renderer
**Новый файл**: `tile/TileRenderer.kt`

- ✅ Минималистичный плоский дизайн
- ✅ Цветовая палитра:
  - Равнина: `#A8E6CF` (мягкий зеленый)
  - Холмы: `#D5E1D6` (светло-коричневый)
  - Вода: `#89CFF0` (голубой)
  - Лес: `#567d46` (темно-зеленый)
  - Горы: `#8B7355` (коричневый)
  - Пустошь: `#E8D4B8` (песочный)
- ✅ Border для визуального разделения

## Фаза 4: Экспорт ассетов ✅

### 4.1 JSON-формат
**Новый файл**: `export/TileMapSerializer.kt`

```json
{
  "version": "1.0",
  "tileSizeCm": 5.0,
  "tiles": [
    {"type": "Plains", "x": 0, "y": 0, "rotation": 0},
    {"type": "Water", "x": 1, "y": 0, "rotation": 0},
    {"type": "Hills", "x": 0, "y": 1, "rotation": 90}
  ],
  "bounds": {
    "minX": 0, "maxX": 5, "minY": 0, "maxY": 3
  }
}
```

### 4.2 PNG-спрайт-лист
**Новый файл**: `export/SpriteSheetExporter.kt`

- ✅ Генерация спрайт-листа (64x64 tiles)

### 4.3 libGDX-формат (опционально)
